# Weather to Wear — CCT360 Data as Experience

Weather to Wear is an interactive web experience that uses live weather data from the Open-Meteo API to generate a fashion recommendation.

## Core idea
The website treats data as a design material rather than just displaying numbers. Live weather changes:
- the outfit illustration
- the outfit title and description
- the styling note
- the accessory recommendation
- the colour atmosphere of the page
- the data-signal graphics

## User interactions
1. Choose a city
2. Refresh live weather data
3. Choose a gender (Women / Men)
4. Choose an occasion (Casual / Dressed Up)

## Data-driven properties
1. Temperature changes the outfit category (cold / mild / hot)
2. Precipitation changes the accessory recommendation and precipitation graphic
3. Wind changes the styling note and wind-signal graphic
4. Weather category also changes the page atmosphere / colour mood

## Files included

- HTML
- CSS
